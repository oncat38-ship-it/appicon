             Vercel / GitHub での使い方
          

          
    
            
  1. 設定を入力して「Zipファイル」をダウンロードします。
    2. 
            
  2. Zipを解凍し、中身を GitHub リポジトリ にプッシュするか、Vercel にドラッグ＆ドロップでデプロイします。
    3. 
            
  3. スマホの Safari (iOS) または Chrome (Android) でデプロイ後のURLを開きます。
    4. 
            
  4. 
              iOS: 共有ボタン → 「ホーム画面に追加」
    
              Android: メニュー → 「アプリをインストール」
